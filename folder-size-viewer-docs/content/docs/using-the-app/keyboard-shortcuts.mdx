---
title: Keyboard Shortcuts
description: Complete reference for keyboard shortcuts available in Folder Size Viewer.
---

Folder Size Viewer is designed to be completely operable from the keyboard for high-efficiency navigation.

## Global Shortcuts

These shortcuts work from anywhere within the application window:

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| <kbd>Ctrl + K</kbd> | Open Instant Search | Focuses the global Tantivy search modal |
| <kbd>Ctrl + O</kbd> | Browse Folder | Opens the native Windows folder picker dialog |
| <kbd>Ctrl + R</kbd> / <kbd>F5</kbd> | Rescan Folder | Triggers a fresh re-scan of the current active directory |
| <kbd>Esc</kbd> | Cancel / Close | Stops an in-progress scan, clears filters, or closes active modals |
| <kbd>Ctrl + ,</kbd> | Open Settings | Opens the Search Index settings panel |

---

## Navigation Shortcuts

Quickly traverse your directory hierarchy:

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| <kbd>Backspace</kbd> / <kbd>Alt + Up</kbd> | Up One Level | Navigates to the parent directory |
| <kbd>Enter</kbd> | Open / Drill Down | Opens the selected folder row or launches the selected file |
| <kbd>Down</kbd> / <kbd>Up</kbd> | Move Selection | Moves cursor down or up through the virtualized item list |
| <kbd>Home</kbd> / <kbd>End</kbd> | Jump to Edge | Jumps directly to the very first or very last item in the list |

---

## View & Display Shortcuts

Switch layouts and toggle display modes:

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| <kbd>Ctrl + 1</kbd> | Table View | Switches to the high-density table layout |
| <kbd>Ctrl + 2</kbd> | Cards View | Switches to the visual cards grid layout |
| <kbd>Ctrl + 3</kbd> | Charts View | Switches to the top folders and file types charts |

---

## Action Shortcuts

Perform quick actions on selected items:

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| <kbd>Ctrl + Shift + C</kbd> | Copy Path | Copies the absolute filesystem path of the selected item to clipboard |
| <kbd>Ctrl + E</kbd> | Show in Explorer | Opens Windows File Explorer and selects the item |
| <kbd>Ctrl + F</kbd> | Focus Filter | Jumps directly into the inline directory filter text box |
