**Folder Size Viewer** is a fast, lightweight, Windows-first desktop application designed to help you visualize disk usage and find any file or text content across your system in milliseconds.

Built with **Tauri v2**, **React**, **TypeScript**, and **shadcn/ui**, the app combines the performance and safety of a native Rust backend with a clean, responsive modern interface.

<Callout type="info" title="100% Offline & Safe">
  Folder Size Viewer is strictly read-only and local-first. It never deletes or alters your files, makes zero network requests, and collects zero telemetry.
</Callout>

## Why Folder Size Viewer?

As disks grow into terabytes and modern dev environments generate hundreds of thousands of files in `node_modules` or build caches, finding what is consuming storage often becomes sluggish:

- **Slow directory scans**: Traditional tree analyzers can freeze your system or take minutes before displaying any actionable data.
- **Disconnected file search**: Disk space tools rarely offer full-text search, forcing you to switch between multiple utilities.
- **Accidental modification risks**: Many cleanup utilities tempt dangerous one-click deletions without granular inspection.

Folder Size Viewer solves this by providing **live streaming results**, dual **Table and Cards views**, **visual storage breakdown charts**, and an embedded **Tantivy full-text search engine** in a single desktop binary.

## Technical Architecture

Under the hood, Folder Size Viewer is built on two primary layers:

1. **Rust Core (Tauri v2)**:
   - High-throughput asynchronous directory walker using multithreaded workers.
   - Non-blocking event streaming to emit partial scan updates to the UI every few milliseconds.
   - Embedded Tantivy search engine indexing file names and text file contents into local inverted indexes.
2. **Frontend UI (React & Tailwind CSS)**:
   - Built on shadcn/ui design patterns for crisp borders, neutral palettes, and dark mode support.
   - Virtualized lists (`@tanstack/react-virtual`) capable of smoothly rendering hundreds of thousands of scanned rows at 60 FPS.
   - Interactive charts powered by Recharts.
