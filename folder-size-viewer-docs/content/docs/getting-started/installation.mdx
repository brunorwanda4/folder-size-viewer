title: Installation
description: Install Folder Size Viewer on Windows via prebuilt binary or build from source.
---

Folder Size Viewer is distributed as a lightweight native Windows executable with no runtime dependencies.

## System Requirements

- **Operating System**: Windows 10 (version 1809+) or Windows 11 (64-bit).
- **Runtime**: Microsoft Edge WebView2 (included by default on Windows 10/11).
- **Hardware**: Minimum 4 GB RAM, 50 MB free disk space for the app binary. Additional disk space may be utilized if you enable full-text content indexing.

---

## Installation Methods

<Tabs items={['Prebuilt Executable', 'Build from Source']}>
  <Tab value="Prebuilt Executable">
    The simplest way to run Folder Size Viewer is downloading the prebuilt standalone Windows binary.

    <Steps>
      <Step>
        ### Download the Release
        Visit the repository's [Releases](https://github.com/brunorwanda4/folder-size-viewer/releases) page on GitHub and download `folder-size-viewer.exe` from the latest release.
      </Step>
      <Step>
        ### Launch the Application
        Double-click `folder-size-viewer.exe`. It is fully portable and requires no installation.
        <Callout type="info" title="Windows SmartScreen">
          If Windows SmartScreen displays an *Unrecognized app* alert on first launch, click **More info** and then select **Run anyway**. This appears because the binary is built with a community certificate.
        </Callout>
      </Step>
      <Step>
        ### Ready to Use
        Folder Size Viewer will open immediately. You can pin it to your Windows Taskbar or Start Menu for quick access.
      </Step>
    </Steps>
  </Tab>

  <Tab value="Build from Source">
    If you prefer to compile from source or contribute to development, you can build the native Tauri binary locally.

    ### Prerequisites

    Ensure you have the following installed on your Windows development environment:
    - **Node.js** (v20 or higher) and **Bun** (or npm/pnpm).
    - **Rust & Cargo** (installed via [rustup.rs](https://rustup.rs)) targeting `x86_64-pc-windows-msvc`.
    - **C++ Build Tools**: Visual Studio Build Tools with the *Desktop development with C++* workload.
    - **WebView2**: Windows 10/11 includes this out of the box.

    ### Build Instructions

    <Steps>
      <Step>
        ### Clone the Repository
        ```bash
        git clone https://github.com/brunorwanda4/folder-size-viewer.git
        cd folder-size-viewer
        ```
      </Step>
      <Step>
        ### Install Dependencies
        ```bash
        bun install
        ```
      </Step>
      <Step>
        ### Build Native Application
        ```bash
        bun run tauri build
        ```
        The compiled executable will be located in:
        ```
        target/release/folder-size-viewer.exe
        ```
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Updating the App

When a new version is released:
1. Download the latest `folder-size-viewer.exe` from the Releases page.
2. Replace your previous executable. Your local search index and configuration settings stored in `%LOCALAPPDATA%\folder-size-viewer` are automatically preserved.
