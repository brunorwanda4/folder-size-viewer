## v1.0.0 (Latest Release)

*Initial stable release of Folder Size Viewer on Tauri v2.*

### Added
- **Asynchronous Scanner**: Multithreaded directory walker with real-time IPC batch streaming and cancel capabilities.
- **Path Auto-Resolution**: Support for Windows environment variables (`%LOCALAPPDATA%`, `%USERPROFILE%`, `%TEMP%`) and home tilde (`~`).
- **Dual Display Modes**: High-density Table View and visual responsive Cards View with Material Icon Theme badges.
- **Breadcrumb Navigation**: Deep drill-down into nested directories with one-click parent traversal.
- **Visual Storage Charts**: Top folders bar chart with automatic "Others" aggregation and storage breakdown across 10 file types.
- **Tantivy Full-Text Search**: Sub-millisecond instant search across file names and plain-text file contents with scope selection.
- **Search Index Manager**: Configurable indexing locations, custom exclusion lists, and 2 MB content threshold settings.
- **Read-Only Safety**: Automatic exclusion of symlinks and NTFS junctions to prevent infinite recursion and double counting.
