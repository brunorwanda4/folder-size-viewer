## Directory Breakdown

- **`src/`**: The React + TypeScript frontend application. Built using Vite, Tailwind CSS, Lucide icons, and Material Icon Theme indicators.
- **`src-tauri/`**: The native Rust application. Contains the Tauri v2 configuration, multithreaded directory walker (`src/scanner/`), and embedded Tantivy search indexer (`src/search/`).
- **`folder-size-viewer-docs/`**: The documentation website built with Next.js (App Router), Fumadocs, and Tailwind CSS v4.
