---
title: Building the Installer
description: Compile an optimized release executable and generate the Windows installer.
---

To package Folder Size Viewer for distribution, generate a production bundle using Tauri's CLI.

## Production Build Command

Run the build script from the root repository directory:

```bash
bun run tauri build
```

### What Happens During Build:
1. **Frontend Optimization**: Vite bundles and minifies all TypeScript, React, and CSS assets into `dist/`.
2. **Rust Release Compilation**: Cargo compiles the backend with `--release` flags, activating Link-Time Optimization (LTO) and stripping debug symbols for minimum binary size.
3. **Installer Packaging**: Tauri invokes the WiX Toolset / NSIS generator to package the executable into standalone Windows installer files.

---

## Output Artifacts

Upon successful completion, the installer files will be located in:

```
src-tauri/target/release/bundle/msi/
src-tauri/target/release/bundle/nsis/
```

- **`.msi`**: Standard Microsoft Windows Installer package. Ideal for enterprise deployments and silent installs.
- **`.exe` (NSIS)**: Modern setup wizard with customizable install directory and desktop shortcut options.
- **Standalone `.exe`**: Located directly in `src-tauri/target/release/folder-size-viewer.exe` for portable usage without installation.
